# Gemini 단가표 출처

`ai_prices.json`은 Google Gemini Developer API 공식 가격 페이지의 유료 등급(Standard) 텍스트 단가를 100만 토큰당 USD로 옮긴 것이다. 추정값은 없다.

- 출처: https://ai.google.dev/gemini-api/docs/pricing (페이지 갱신일 2026-10-28 UTC, 옮긴 날 2026-10-29)
- 키는 호출에 쓰는 모델 ID와 글자 그대로 같아야 한다. 표에 없는 모델은 비용이 null로 남는다(추정하지 않음).
- 2026-12-31까지 가격이다. gemini-3.6-flash·gemini-3.8-flash는 2027-01-01부터 입력 1.50, 출력 3.75→7.50, 캐시 0.15로 오른다고 적혀 있다. 그때 `as_of`와 값을 새로 옮긴다.
- gemini-3.1-pro-preview는 프롬프트 20만 토큰 이하 단가만 넣었다. 20만 초과(입력 4.00, 출력 18.00, 캐시 0.40)는 표 구조가 단일 단가라 넣지 않았으므로, 긴 프롬프트 실험은 비용을 따로 계산한다.
- 임베딩 모델은 입력 단가만 있다. 출력·캐시 0은 "없음"을 뜻한다.
- 캐시 저장 요금(시간당)과 Batch·Flex·Priority 등급, 오디오·이미지·영상 입력 단가는 옮기지 않았다.
- 변경 시 `tests/test_ai_client.py`의 단가표 로딩 검사가 형식을 확인한다.
