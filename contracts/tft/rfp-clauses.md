## 조항 트리

제공 RFP는 제목 서식·자동 번호가 없다(14번은 문단 703개가 모두 `Normal`, `hints.list_text` 0개). 그래서 문단 앞 번호 글자로 깊이를 정한다.

| 깊이 | 패턴 | 조항 번호 |
| --- | --- | --- |
| 1 | `PART 2 - PRODUCTS` | `PART 2` (제목 `PRODUCTS`) |
| 2 | `2.5 EPOXY …` | `2.5` |
| 3 | `C.` | `2.5.C` |
| 4 | `1.` | `2.5.C.1` |
| 5 | `a.` | `2.5.C.1.a` |
| 6 | `1)`·`(1)` | `2.5.C.1.a.1` |
| 7 | `a)`·`(a)` | `2.5.C.1.a.1.a` |

| 문서 배치 | 처리 | 표시 |
| --- | --- | --- |
| 줄이 중간에서 끊긴 문단 | 앞 조항에 공백으로 잇는다(앞 글이 문장 끝이 아니거나 소문자로 시작) | `LINE_BREAK_REJOINED` |
| 페이지 머리말·바닥글이 본문 문단으로 들어옴 | 숫자를 지운 모양이 3번 이상 반복되는 번호 없는 짧은 문단이 **모양이 다른 반복 문단과 붙어** 나올 때만 뺌. 혼자 반복되는 `Provide the following:` 같은 본문은 남김. 삭제 값이 있는 문단은 빼지 않음 | `excluded`(글·이유와 함께) |
| `END OF SECTION`과 그 뒤 문단 | 절 밖이라 조항에 붙이지 않음 | `excluded` |
| 끊긴 줄이 소수로 시작(`13.8 kV class`) | 지금 PART 번호와 같고 앞 절보다 큰 번호만 절로 읽음 | — |
| 번호가 표 칸에 있음(왼쪽 `D.`, 오른쪽 본문) | 그 행을 번호 조항으로 읽는다 | `FROM_TABLE_ROW` |
| 절 번호가 표 칸에 떠 있음(`2.2 A.`) | 뒤가 본문이면 그 자리에서, 뒤가 번호 칸이면 번호가 `1`로 다시 시작하는 곳에서 절을 연다. 다음 절·문서 끝까지 못 찾으면 그 자리에서 열고 보고 | `DEFERRED_ARTICLE`, `UNPLACED_ARTICLE` |
| 한 문단에 항목 두 개(`… open. b. Expulsion …`) | 문장 끝 뒤에 **같은 깊이의 다음 번호**가 대문자 앞에 올 때만 나눈다. 나눈 자리 안의 삭제 값도 보존하고, 블록 출처는 나눈 위치로 정한다 | `INLINE_SPLIT` |
| 번호 건너뜀·반복 | 고쳐 쓰지 않고 남긴다. 반복은 `~2`를 붙인다 | `numbering_issues` |

## 일반 한글 번호

- `제1장`·`제 1 장`은 깊이 1, `제1조`·`제1조(목적)`은 깊이 2다. 번호를 그대로 `label`에
  남기고 내부 번호의 공백만 정리한다(`제1장`, `제1조`). 조는 장을 `parent_no`로 가리키되 조항 번호는
  영문 절과 같이 독립한다. 예: `제1장` → `제1조` → `제1조.1` → `제1조.1.가`.
- 한글 문맥에서 숫자 항목은 깊이 3, `가.`·`나.`는 4, `(1)`은 5, `(가)`는 6이다. 조 앞에 장이
  없어도 조에서 시작한다. 조의 괄호 제목과 이어지는 본문은 `text`에 보존하고 제목으로 빼지 않는다.
- PART·장·조가 없는 문서의 `1. 일반`·`2.절차`처럼 한글로 시작하는 숫자 제목은 깊이 2 절로
  읽는다. 특정 문서의 제목이나 문구로 분기하지 않는다. 명시 장/조/PART가 있는 문서는 그 앞 표지의
  숫자 항목을 새 절로 승격하지 않는다.
- 한글 번호 문맥의 `13.8 kV`, `0.5 밀리미터` 같은 소수와 표의 `1.5 A.`는 영문 `2.5` 절이나
  떠 있는 절 번호로 오인하지 않고 본문/표로 남긴다. 한글 문맥의 소수형 번호는 절로 분리하지 않는다.
  다음 `PART`가 나오면 영문 깊이·절 번호 판정으로 돌아간다. 기존 영문 회귀는 그대로 유지한다.
- 번호 없는 문단, 삭제 값 위치, 표 셀 출처는 기존 방식으로 보존한다. 위 규칙은 조항 트리 복원이며
  모델·DB·문서별 고정 문구를 사용하지 않는다.

## 편집 흔적

**현행 텍스트가 요구이고 삭제 값은 이력이다.** 서식을 버린 텍스트 추출은 지운 값과 남은 값이 붙어 읽힌다(2.5 C.1 "5033%"). 조항마다 원문 복원(`original`)과 현행(`current`)을 따로 낸다.

| 종류 | 판정 | 해석 |
| --- | --- | --- |
| `RENUMBER` | 번호 자리의 삭제(`label_history`) | 번호만 바뀜. 현행 번호로 조항을 찾는다 |
| `SCOPE` | 괄호 문구 삭제 | 범위 표시가 지워짐. 조항 전체가 현행 범위 |
| `TYPO` | 두 글자 이하 영문자가 단어에 붙어 지워짐 | 의미 변화 없음 |
| `VALUE` | 그 밖(숫자·낱말) | 현행 값을 요구로 쓰고 지운 값은 이력 |

군: 사람이 한 번 판단하면 되는 단위다. 번호 다시 매김은 절마다 한 군, 값·범위·오탈자는 흔적 하나가 한 군이다. PDF는 `status=UNSUPPORTED`("편집 흔적 확인 불가")이며 0건을 "없음"으로 보고하지 않는다.

## 14번 결과 (2026-10-29, `261116.11 … switchgear secondary`, 읽기 전용)

- **블록 배치**: 빈 칸이 아닌 블록 757/757이 조항·머리말·반복 문구 중 한 곳에 들어갔다(빠진 블록 0).
- **조항**: 552개(PART 3 · 절 26 · 깊이 3~7 523). 절은 1.1~1.9, 2.1~2.9, 3.1~3.8로 원문 목차와 같다.
  - 이어 붙인 조항 71, 표 행 조항 24, 한 문단에서 나눈 조항 14, 미룬 절 1(2.2)
  - 뺀 문단 85: 페이지 머리말·바닥글 83, `END OF SECTION` 1, 그 뒤 마지막 바닥글 1
- **번호 문제**: 3건. 모두 건너뜀이고 원문 확인 대상이다(2.6.C 1→5, 2.6.E.4 e→g, 3.6.C 1→3).
- **취소선**: 22/22를 보존했다(A02 기준 22곳과 같음). **8군**으로 묶인다.

이 결과는 저장소 밖 원문으로 로컬에서 확인했다. 원문·추출물은 커밋하지 않는다. 검사는 같은 배치를 흉내 낸 합성 블록으로 한다.

한글 장·조·독립 숫자 절은 하위 번호가 없는 leaf라도 본문·표가 있으면 처리 절에 포함한다. 실제 자식이 있는 장은 leaf로 중복 선정하지 않는다. 영문 PART 문서의 기존 절 선정과 추출 입력은 유지하며, 새 한글 leaf 입력은 머리 본문 fallback으로 한 번만 전달한다.
