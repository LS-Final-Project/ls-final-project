# RFP 문서 manifest (KAN-197)

`rfp-documents-20261029-v1.json`은 개발 14·17번과 평가 10·11·12·18번의 파일명·바이트
SHA-256·허용 목적을 고정한다. 원문·정답·문서 내용은 포함하지 않는다.

```bash
python -m eval.rfp_manifest /path/to/RFP_Cleansed_styled_v6
```

평가 문서는 모델·프롬프트 선택에 쓰지 않는다. 고정 후 첫 실행이 공식 점수이며 수정 후
재측정은 참고값으로 구분한다. 15번 회귀 문서는 평가 4건의 분모와 별개다.

번호 대응과 해시는 2026-10-29에 두 가지로 확인했다. Drive 원본 `문서속성_22건.csv`
(2026-10-21 작성, D번호·파일명)와 `sources.json`(같은 날, `docx_sha256`)을 다시 읽어
6개 문서의 D번호·파일명·SHA-256이 이 manifest와 같음을 대조했고, 로컬 6개 DOCX의 바이트
해시도 `python -m eval.rfp_manifest`로 일치를 확인했다. 원본 목록이 10/21 이후 바뀌지
않았다는 것까지 보장하지는 않는다(이후 판본이 생기면 새 manifest로 고정한다). 분할 근거는 KAN-191의 현행
설명과 그 설명이 가리키는 2026-10-28 기획서 §3.2다.

10/21 목록에서 DEVELOPMENT_EXPOSED였다는 이전 조사 기록을 보존한다. 이 manifest의
평가 지정은 과거 노출을 지우지 않으며 독립 미노출 최종셋을 확보했다는 뜻이 아니다.
평가 실행·첫 실행 여부·모델/프롬프트 동결 확인은 KAN-191에서 별도로 기록한다.
