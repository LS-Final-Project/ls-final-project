# 셋업과 온보딩 재검토

2026-10-22 사용자가 아스트라 세션으로 독립 검토하고 필요한 코드 및 공통 온보딩과 이름별 문서를 수정하도록 요청했다. gpt-6-astra는 읽기 전용으로 결함을 검토했고 주 세션이 수정 및 실제 실행을 맡았다. 수정본은 아스트라가 재검토했다. 실행 골격의 정상 동작과 제품 전체 기능 구현 완료를 구분한다.

## 발견과 수정

| 분류 | 문제 | 반영 |
| --- | --- | --- |
| 첫 실행 차단 | Compose가 Docker 빌드에 SERVICE_NAME을 주지 않아 기본 cs 이미지에서 다른 서비스 모듈이 삭제됨 | cs, tft, platform별 빌드 인자를 지정하고 실제 새 DB 및 세 API 실행 검증 |
| CI 누락 | compose.yaml을 검사 대상에서 제외 | infrastructure 검사에 연결하고 Docker Compose의 실제 config 결과에서 빌드 및 런타임 서비스 이름을 대조하는 회귀 추가 |
| CI 누락 | 생성된 mock JSON만 바꾸면 원본 일치 검사 생략 | 해당 서비스 계약 검사를 선택하며 클라우드 배포는 선택하지 않음 |
| CI 누락 | cs/tft 검사에서 공유 engine과 agent 경로의 lint 및 타입 검사 누락 | 경로가 존재할 때 해당 소비자의 검사에 포함하고 명령 선택 회귀 추가 |
| 예방 보완 | 향후 Markdown 프롬프트가 일반 문서 제외 규칙에 걸릴 수 있음 | backend/agent와 engine의 런타임 파일을 문서 제외보다 먼저 분류 |
| 공통 안내 | 비공개 저장소 인증과 Git 작성자 설정, WSL 준비와 터미널 사용 및 첫 PR의 구체 순서 부족 | docs/team-start.md에 단계와 정상 결과, 재실행 및 문제 해결 안내 보강 |
| 이름별 문서 | WBS 표와 toggle 속성이 문자로 저장되고 파일명이 외부 웹 링크로 변환됨 | 스프린트별 실제 표로 복구하고 파일명을 코드로 표시. 공통 안내는 dev 원본에 연결 |

## 실제 검증

기존 .env, data와 DB 및 사용자 컨테이너를 사용하지 않았다. 추적된 소스의 별도 임시 복사본에서 외부 인증 및 모델 설정 없이 검증했다. 별도 Compose 프로젝트와 새 DB 볼륨 및 임의 API 포트를 사용했다.

- 최초 setup의 의존성 잠금 설치, 로컬 설정 생성 및 타입 생성 PASS
- up 및 check에서 PostgreSQL 17, 서비스별 DB 계정과 스키마, pgvector 및 FTS와 세 API readiness PASS
- 합성 사용자 4개, 실제 DB 세션과 역할, 미등록 사용자 거부와 Origin 검사 및 로그아웃 PASS
- DB CRUD와 교차 스키마 및 DDL 거부 행렬 PASS
- frontend production 빌드 및 contracts all --check PASS
- 키를 사용하지 않는 fake 평가의 JSON 및 HTML 기록 PASS
- Git 저장소에서 커밋 훅 설치 PASS. 기존 Git 자동화 회귀에서 실제 dev 기반 분기 및 메시지 처리도 검증
- Vite 서버 HTTP와 세 API 프록시, 계정 목록 4개와 프록시를 통한 쿠키 세션 및 로그아웃 PASS
- scripts 38건, infra 21건, PR 자동화 14건과 관련 Ruff 검사 PASS

검증용 컨테이너 및 볼륨을 정리했다. 사용자 PC의 Windows 설치와 GitHub 조직 초대 및 본인 브라우저 로그인까지 대신 검증한 것은 아니다. 이 단계는 공식 설치 및 인증 안내를 제공하고 사용자 환경에서 확인한다. 실제 모델 및 메일을 추가 호출하지 않았고 최종 test 597건과 OpenDesign 원본을 사용하지 않았다. GCP 리소스와 IAM을 변경하지 않았다.

## 문서와 역할 보존

설치부터 첫 PR까지는 [공통 온보딩](team-start.md) 한 곳에서 유지한다. 이름별 문서에는 읽는 순서, 이미 완료된 기반과 첫 PR의 범위 및 담당 경계를 보강했다. 전체 WBS 조회 목록은 김나영 35건, 오새결 48건, 김종하 35건이며 118건의 작업 링크와 날짜를 수정 전후 대조했다. 원본 WBS와 Jira 담당자 및 일정, 스프린트는 변경하지 않았다. 이름별 문서의 자동 알림이나 검토 요청을 보내지 않았다.
